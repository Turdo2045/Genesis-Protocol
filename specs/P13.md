## Abstract

Cross-generational transmission of a trained companion persona (affective
weights) without probate, notaries, or identity registries. Control is
bound to asymmetric keypairs; the inheritance trigger is a liveness
heartbeat; the handover is atomic and burns the prior control surface —
the matrix is **ephemeral**.

## Motivation

Probate converts death into a state-mediated transfer tax and a privacy
breach. P-13 replaces the death certificate with a silence window and the
court with a signature check.

## Specification

### Primitives

```solidity
function registerVault(bytes32 personaCommitment, bytes32 ownerCommitment,
    bytes32 heirCommitment, uint64 heartbeatInterval, bytes calldata ownerSig)
    external returns (uint256 id);
function heartbeat(uint256 id) external;                 // owner's only duty
function rotateHeir(uint256 id, bytes32 newHeirCommitment) external;
function claimInheritance(uint256 id, bytes32 newPersonaCommitment,
    bytes calldata heirSig) external;                    // THE CORE PRIMITIVE
function triggerCountdown(uint256 id) external view returns (uint64);
```

### Invariants (machine-checked in `test/P13.t.sol`)

1. **Silence-armed trigger** — claim succeeds iff
   `block.timestamp > lastHeartbeat + heartbeatInterval`.
2. **Key-bound agency** — owner and heir are `H(pubkey || salt)`
   commitments; no legal identity exists on-chain.
3. **Ephemerality** — at claim, `controllerOf[ownerCommitment]` is
   deleted; the old surface is unrecoverable.
4. **Terminality** — double claim reverts.
5. **Liveness reset** — a heartbeat re-arms the full window.

### Off-chain ceremony (see `pseudocode/p13_persona_inheritance.py`)

Inheritance payload transfer uses proxy re-encryption: ciphertext is
transformed from owner-key to heir-key without plaintext exposure; the
old ciphertext is zeroized.

## Rationale

- **Heartbeat, not oracle**: any external death oracle is a state
  interface; silence is endogenous and uncensorable.
- `heartbeatInterval` floor (≥ 1 day) resists accidental arming;
  interplanetary deployments should use P-15's block-number basis.

## Security Considerations

- Key loss = persona loss. There is no recovery path by design; a
  recovery registrar would be an identity surface.
- A coerced heartbeat delay is indistinguishable from death — see the
  duress discussion in `docs/COUNTERFACTUAL_ROBUSTNESS.md`.

## Backwards Compatibility

Frozen minimal reference. Self-succession (substrate migration) is NOT
inheritance and routes via P-15 `rotateControl`.
