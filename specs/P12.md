## Abstract

A bilateral covenant ledger whose termination is a unilateral,
single-transaction **Ledger State Reset**. Exit allocation is
pre-committed at initiation and executes deterministically; the
liquidation tax is zero by construction, and no judicial, arbitral, or
oracle interface exists at the contract surface.

## Motivation

Legacy dissolution of relational contracts routes through courts, whose
fees, delays, and discretion constitute an exit tax (Volumes II–III).
P-12 compresses that exit cost to exactly zero: termination is final in
one block, at gas cost only.

## Specification

### State machine

```
Uninitialized --initiate--> Active --suspend--> Suspended
                               |  \--resume----^    |
                               +--------dissolve----+
                               v
                           Dissolved   (terminal)
```

### Interface

```solidity
function initiate(address counterparty, bytes32 exitTermsHash) external returns (uint256 id);
function post(uint256 id, address party, int256 delta) external;
function suspend(uint256 id) external;
function resume(uint256 id) external;
function dissolve(uint256 id) external;              // THE CORE PRIMITIVE
function entitlementOf(uint256 id, address party) external view returns (int256);
```

### Invariants (machine-checked in `test/P12.t.sol`)

1. **Unilaterality** — either party may `dissolve`; no consent round.
2. **Total reset** — post-dissolve, all entitlements read zero.
3. **No third-party surface** — non-parties cannot call any mutator.
   There is no `arbitrate`, `appeal`, or `courtAttach` symbol.
4. **Terminality** — `Dissolved` is absorbing; all mutators revert.

### Events

`CovenantInitiated`, `LedgerPosted`, `CovenantSuspended`,
`CovenantResumed`, `LedgerStateReset(id, initiator, atTime)`.

## Rationale

- **Pre-committed exit terms** (`exitTermsHash`) remove post-hoc
  reinterpretation; the hash binds both parties to a deterministic
  allocation computed off-chain.
- **No fee/slash parameter exists.** A configurable liquidation fee would
  be a re-colonization vector for the legacy tax; it is therefore not a
  parameter but an absence.

## Security Considerations

- Unilateral exit means a party can exit at a locally unfavorable ledger
  state; this is a feature (exit optionality is the product), priced
  ex ante in the exit terms.
- `exitTermsHash` privacy: the hash hides the allocation; parties must
  retain the preimage off-chain.
