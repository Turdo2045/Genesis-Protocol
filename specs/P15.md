## Abstract

A generalization layer that frees the protocol stack from three
baseline-human assumptions: secp256k1-only authentication, Earth-second
time, and single-mind agency. Authentication becomes a pluggable
`IControlVerifier`; time becomes a per-entity basis (`ChainTime` |
`BlockNumber`); agency becomes composable (threshold verifier for
collective minds).

## Motivation

Counterfactual analysis (`docs/COUNTERFACTUAL_ROBUSTNESS.md`) shows
P-12/13/14 break for BCI (coerced neural signatures), uploads (undefined
death), composites (catastrophic unilateral exit), interplanetary and
trans-dimensional counterparties (Earth-second windows), and
non-terrestrial cryptography. P-15 absorbs all of these without
reintroducing judiciary, identity registry, or probate.

## Specification

### Components

- **`IControlVerifier`** — `verifyControl(commitment, digest, authData)
  → bool`. Any signature scheme is admissible: ECDSA (reference),
  neural-intent, lattice-based, threshold, or schemes not yet invented.
- **`ThresholdVerifier`** — m-of-n over member keys; duplicate signers
  and sub-quorum submissions revert. One sub-mind can never act for the
  collective.
- **`P15_OntologyAgnosticControl`** — entity registry keyed by
  pseudonymous commitment, per-entity `TimeBasis`, and the
  self-succession primitive `rotateControl`.

### Primitives

```solidity
function registerEntity(bytes32 commitment, address verifier,
    TimeBasis basis, uint64 pulseInterval, bytes calldata authData) external;
function pulse(bytes32 commitment, bytes calldata authData) external;
function rotateControl(bytes32 oldCommitment, bytes32 newCommitment,
    address newVerifier, bytes calldata authData) external;  // self-succession
function silenceExceeded(bytes32 commitment) external view returns (bool);
```

### Invariants (machine-checked in `test/P15.t.sol`)

1. **Pluggable auth** — entities register and pulse under any registered
   verifier; wrong-scheme auth reverts.
2. **Threshold agency** — single sub-mind fails, m-of-n succeeds,
   duplicate signers fail.
3. **Self-succession** — `rotateControl` migrates control to a new
   commitment/verifier and burns the old anchor; no inheritance is
   triggered.
4. **Non-Terran time** — `BlockNumber` basis is delay-immune;
   `ChainTime` intervals below 1 hour (≥ 2× worst-case Earth–Mars light
   delay + margin) are refused at registration.

## Rationale

- **Registry, not hardcode**: P-12/13/14 hardcode `ecrecover` because
  minimalism is their specification goal; P-15 exists so they never need
  to change.
- **Self-succession ≠ inheritance**: substrate migration by a living
  entity must not consume the death-trigger semantics of P-13.

## Security Considerations

- A malicious verifier contract can forge its own entities' auth; the
  registry is permissionless by design — counterparties MUST audit the
  verifier address before covenanting with an entity.
- Coercion (forced neural signing) is out of the cryptographic model;
  see the optional duress-flag policy discussion in the analysis doc.
  It is off by default because enabling it trades against P-12's
  zero-friction invariant, and that trade must never be silent.

## Backwards Compatibility

P-12/13/14 remain frozen minimal references. P-15 is additive.
