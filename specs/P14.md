## Abstract

Edge devices destroy raw audio and multimodal captures in-enclave and
anchor only irreversible ZK state proofs on-chain. The contract's input
surface accepts exclusively `bytes32` commitments and proof bytes — raw
media is **type-system-impossible** to submit. Physical seizure of the
device or the ledger yields nothing: the coercive actor's tax base does
not exist.

## Motivation

Volume III documented state interdiction of the domestic boundary. P-14
makes that interdiction economically void: there is no subpoena-able
third-party asset because there is no asset.

## Specification

### Interface

```solidity
function registerDevice(bytes32 deviceCommitment) external;
function submitStateProof(bytes32 deviceCommitment, bytes32 nullifier,
    bytes32 newStateCommitment, bytes32 epochCommitment,
    bytes calldata proof) external;                      // THE CORE PRIMITIVE
```

`submitStateProof` public inputs, in order:
`[deviceCommitment, nullifier, newStateCommitment, epochCommitment]`.

### Invariants (machine-checked in `test/P14.t.sol`)

1. **Nullifier single-use** — replay reverts; one proof, one transition.
2. **Device gating** — unregistered device commitments cannot anchor.
3. **Proof gating** — invalid proofs touch no state.
4. **Commitment-only storage** — `latestState` and `spentNullifiers` are
   the entire state surface; no media, embeddings, or pointers exist.

### Edge pipeline (see `pseudocode/p14_edge_zk.py`)

```
capture → in-enclave feature extraction → DP noise (ε-bounded)
        → full-feature zeroization → ZK proof over public inputs
        → transmit payload ONLY (no raw artifact path exists)
```

Device identity is `H(TEE attestation || salt)`; salt rotation rotates
the pseudonym. Verification is delegated to an `IZKVerifier` contract,
decoupling the anchor from any specific proof system.

## Rationale

- **Destruction before proof**: the witness is zeroized before the proof
  leaves the enclave, so even a compromised post-hoc device cannot
  reconstruct what was proven about.
- **Verifier indirection**: proof systems age; the anchor must not.

## Security Considerations

- The security reduction assumes enclave integrity; a broken TEE leaks
  captures before zeroization. Mitigation is hardware rotation, not
  protocol change.
- Nullifier derivation `H(secret, epoch)` must use an epoch granularity
  that matches the intended transition rate.

## Backwards Compatibility

Frozen minimal reference. Non-simian / non-terrestrial attestation
schemes route via P-15 verifier composition.
